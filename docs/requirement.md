### 1. 사이트 목적 및 대상 사용자
- 사이트 목적: 이 사이트는 ['랭킹닭컴'](https://www.rankingdak.com/?srsltid=AfmBOoosMK50w9BKm7tuhgTLOs-PKnDFDslxaTrRpUo1G_2kYQEDmU1f) 웹사이트 이미지를 바탕으로 클론 코딩하는 것으로, 커머스(E-commerce) 플랫폼의 구조를 가지고 있으며, 모바일 반응형 대응이 중요한 사이트. '적응형 웹(Adaptive Web)' 또는 '웹뷰 스타일'로 구현.
- 대상 사용자: 닭가슴살 구매하려는 사용자가 주 고객층임.
- 왜 필요한가? 요즘 웹 형식의 사이트보다 웹을 앱 형태로 보여주는 사이트가 늘어나고 있어서 템플릿 형식 같이 사이트를 개발해 두기 위함. 템플릿 형식이기 때문에 Mock 데이터를 활용해서 개발을 진행.

### 2. 주요 기능 및 페이지 구성
- 필수 페이지:
    - 상품 리스트 페이지 (Category/Ranking): 랭킹닭컴의 핵심인 '카테고리별 순위'를 보여주는 페이지. 필터링(가격순, 인기순) 기능 포함.
    - 상품 상세 페이지 (Detail): 상품 이미지 슬라이더, 가격, 옵션 선택, 상세 설명(이미지), 리뷰/문의 탭.
    - 장바구니 (Cart): 선택한 상품의 수량 조절, 삭제, 총 결제 금액 계산 기능.
    - 마이페이지 (My Page): 주문 내역, 쿠폰, 적립금 등을 확인하는 UI (Mock 데이터 활용).

- 기능:
    - 반응형 디자인: 모바일, 태블릿, 데스크톱 등 다양한 기기에서 잘 보이도록.
    - 디자인: Clean & Modern Minimalism과 Bold & Expressive Typography를 적절히 사용할 것.
    - 간단한 애니메이션/인터랙션: 사용자 경험을 향상시킬 수 잇는 요소 (스크롤 애니메이션, 호버 효과 등).
    - SEO 친화적: 검색 엔진에 노출이 잘 되도록 기본적인 메타태그 설정 등.
    - GNB/LNB 내비게이션: * 하단 고정 탭 바 (Mobile-first): 홈, 카테고리, 마이페이지, AI 식단 등 앱 느낌의 UI 구현.
        - 상단 검색바 및 장바구니 아이콘.
    - Mock Data 관리: public/data/*.json 또는 서버의 API를 통해 상품명, 가격, 이미지 URL, 할인율 등을 관리하여 확장성 확보.
    - 상태 관리 (State Management): 장바구니 담기, 옵션 선택 등을 위해 Zustand 사용.
    - 이미지 최적화: Next.js의 next/image를 사용하여 Layout Shift 방지 및 WebP 포맷 자동 변환.

### 3. 콘텐츠 요구사항
- 텍스트 콘텐츠: 각 페이지에 들어갈 주요 문구, 헤드라인, 설명 등 (AI가 초안을 생성할 수도 있지만, 방향성을 제시).
- 이미지 or 비디오: 저작권에 위배되지 않도록 ['pixabay'](https://pixabay.com)에서 적절한 것을 사용할 것.
- 스켈레톤 UI (Skeleton UI): 데이터가 로딩되는 동안 앱의 레이아웃을 미리 보여주어 사용자 경험(UX) 향상.
- 배너 슬라이더: `Swiper.js` 또는 `Framer Motion`을 활용한 메인 히어로 배너 슬라이드.
- Heroicons 활용: * `Outline` 스타일은 미선택 상태, `Solid` 스타일은 선택된 상태(Active)로 구분하여 사용.

### 4. 성능 및 접근성
- 로딩 속도: 빠른 페이지 로딩 속도 (Core Web Vitals 고려).
- 접근성 (Accessibility): 시각 장애인 등 다양한 사용자를 위한 웹 접근성 고려 (ARIA 속성, 키보드 내비게이션 등)

### 5. 구현계획
- 한 번에 사이트를 완성하지 말고, 단계별 계획을 세워서 만들 것.
    - frontend는 client 디렉터리를 만들어서 할 것.
    - backend는 server 디렉터리만 만들고 진행 하지 말 것.
- plan.md에 계획 내용을 작성해서 저장해서 실제 구현 시 사용할 것.

### 6. 프레임워크
- 프레임워크는 Next.js 14/15 (App Router)로 만들 것.
- 컴포넌트 기능을 최대한 활용할 것.
- 스타일링은 Tailwind CSS로 사용할 것.
